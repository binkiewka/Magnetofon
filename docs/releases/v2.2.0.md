# Magnetofon ST-8000 v2.2.0

A finishing release for dependable native listening, integrated visuals and the compact hi-fi console. The cassette, materials and single native audio/video engine are retained.

## Listening you can trust

- Native playlist-entry correlation prevents delayed EOF/error events from cancelling a new selection; gapless errors identify the failed entry and stop until Retry/Skip.
- Correct track identity on missing/moved/unreadable media, visible loading/playback errors, and Retry/Skip recovery. Activating the current stopped or paused row works.
- Explicit Stereo downmix alongside Auto, 2.1 and Surround. EQ, routing and speaker intent persist between launches.
- Linked look-ahead overload protection for enhanced DSP, enabled by default, without automatic make-up gain or album normalization. Unprocessed Auto/EQ-bypass playback bypasses that enhancement graph.
- Calibrated software attenuation and RMS signal displays replace decorative amplifier-power/dB claims.
- Repeat Off / All / One is independent of Gapless.

## Less work between albums

- Restore the last queue, track and position **paused**, with private atomic session snapshots. Volume still deliberately starts at 50%.
- Content-based explicit imports, extensionless FLAC and additional raw surround suffixes. Background discovery/cancellation and portable M3U8 playlists remain.
- Compact queue search/reveal-current, ordinary arrow navigation and modifier-assisted reorder.
- Keyboard/accessibility support for volume/EQ/seek, standard in-window transport shortcuts, a responsive scrollable narrow rack and proportion-preserving cassette.

## Visuals follow this player

- The bundled Linux projectM frontend restricts PCM capture to the parent Magnetofon process and follows its actual output stream. No fallback to the system mix or microphone and no second decoder.
- Separate Rendering and Audio Live/silent/unavailable status with freshness/recovery reporting.
- Verified full-pack identity stays separate from custom presets; transactional installation retains the current pack and one rollback.
- F/F11 fullscreen, Escape back to a window, G for projectM settings.

## Delivery

- Prebuilt Linux x86-64 targets the Ubuntu24.04 / Mint22 generation (AppImage bundles application libraries, not an older glibc). DEB and AppImage include the patched native visualizer and curated presets; the optional preset installer has its unzip dependency supplied. Video Open With associations are included.
- AppImage visuals prefer the supplied SDL/Pulse libraries rather than depending on copies already installed on the computer.
- Windows x64 ZIP uses checksum-pinned libmpv and exact Qt version, with an extracted-bundle startup check. Native projectM and stream metering remain Linux-only; Windows does not pretend those features are available.
- Release package checksums are supplied in SHA256SUMS.

## First run

Use the Linux DEB with your package manager, or make the AppImage executable (use `APPIMAGE_EXTRACT_AND_RUN=1` if FUSE is unavailable). Extract the entire Windows ZIP; install its included `vc_redist.x64.exe` once if the Microsoft C++ runtime is missing, then run `MagnetofonNative.exe`. Keep all supplied DLL/QML/plugin files together.

## Qualification scope

Native automated tests use synthetic media and isolated state; DSP protection is checked with correlated multichannel bass and boosted settings. These checks are not a certification of physical speakers, HDMI receiver configuration, Bluetooth/USB devices, Windows speaker output or hardware video A/V quality. No bit-perfect or fixed CPU/RSS/frame-rate claim is made.

Existing playlists, custom presets and saved speaker profiles are retained. The new session snapshot is per-user application state, not an uploaded library.
